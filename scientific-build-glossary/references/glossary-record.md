# Терминологическая статья и неоднозначности

## Минимальная запись

| Поле | Назначение |
| --- | --- |
| ID | Устойчивый идентификатор термина |
| Термин | Предпочтительная форма на языке рукописи |
| Соответствия | Другие языки, допустимые варианты и сокращения |
| Смысл | Краткое пояснение в контексте темы |
| Основание | ID публикации, ссылка и конкретное место употребления |
| Статус | Употребление в источнике, авторское определение, предложенный перевод или термин проекта |

Можно объединить статус с основанием, если это не скрывает происхождение. Для сложного понятия добавить условия применимости, формулу, единицы и отличие от соседнего понятия. Не требовать формулы для понятий, которые определяются содержательно.

## Два независимых вида статуса

Происхождение: найдено в проверенном тексте, предложено составителем, введено автором проекта. Принятие: кандидат, принято в рукописи, прежний вариант. Принятие перевода пользователем не превращает его в подтверждённый русский термин из иностранного источника.

При наличии только аннотации явно указать этот объём. Если нужного слова в проверенной части нет, не ссылаться на статью как на подтверждение его употребления. Можно отдельно сослаться на неё как на смысловой контекст и обозначить собственную формулировку.

## Разбор неоднозначности

Для конфликтующей пары указать:

1. Контексты и объекты, в которых термины употребляются.
2. Смысловое различие и последствия смешения.
3. Выбранную формулировку для рукописи.
4. Основание выбора и статус решения.

Примеры типов различий: наблюдаемая связь и причинный эффект, относительный и абсолютный риск, условная и общая вероятность, формальная корректность и экспериментальная точность, исходный текст и исследовательская интерпретация. Эти примеры не являются обязательными терминами любого словаря.

## Если нужны количественные частоты

Вместе с частотами сохранить список реально обработанных версий, правило извлечения, нормализацию и исключаемые зоны. Приписывать результат только этому корпусу. Не заявлять популярность во всей научной области по малому целевому набору.
