# Записи темы и корпуса

Использовать поля, нужные для выбранного типа исследования. Допустимы Markdown, таблица или существующая библиографическая система. Пустое поле означает «не установлено», а не отсутствие свойства в самой работе.

## Описание темы

- Исследовательский вопрос и искомый результат.
- Объект, материал или популяция и единица анализа.
- Тип работы и допустимые виды доказательств.
- Известные условия, неизвестные параметры и ограничения.
- Языки, временной охват и требования к источникам.
- Принятые решения, рабочие предположения и открытые вопросы.

Для теоретической работы вместо экспериментального дизайна могут быть нужны класс объектов, предпосылки и вид утверждения. Для качественного исследования существенны контекст, выбор материала и метод интерпретации. Не заполнять неприменимые поля вымышленными численными аналогами.

## Карточка источника

| Поле | Содержание |
| --- | --- |
| ID | Стабильный локальный идентификатор, например S001 |
| Библиография | Авторы, название, год, издание, DOI или иной идентификатор, ссылка |
| Семейство и версия | Препринт, публикация, перевод, исправление. Какая версия проверена |
| Язык | Язык проверенного текста отдельно от языка аннотации |
| Доступ и проверка | Полный текст, конкретные разделы, аннотация, только запись. Дата доступа |
| Вопрос и результат | Что авторы исследуют и какой результат получают |
| Условия | Материал, исходная информация, предпосылки и границы |
| Метод и доказательства | Эксперимент, анализ данных, доказательство, интерпретация или синтез |
| Близость | Прямой аналог, методический аналог или контекстный источник с объяснением |
| Различие | Что мешает напрямую перенести результат на нашу задачу |
| Основание | Раздел, печатная или PDF-страница, таблица, формула, иной локатор |

Указывать обе нумерации страниц, если печатная и файловая расходятся. Для HTML годится устойчивый заголовок раздела. Локатор не заменяет ссылку на публикацию.

## Журнал поиска и отбора

Зафиксировать фактические запросы и ресурсы, границы поиска, критерии включения, существенные исключения и остановку поиска. Причина остановки может быть содержательной: основные подходы представлены, новые запросы дают дубли, ближайшие доступные аналоги проверены. Это не доказательство исчерпывающего охвата.

## Передача следующему этапу

Отдельно обозначить ядро ближайших работ и доступные места употребления терминов. Сохранить ID при подготовке словаря и анализа структуры. Не передавать предположение, сделанное по аннотации, как установленную характеристику полного текста.
