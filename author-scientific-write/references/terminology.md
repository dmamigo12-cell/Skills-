# Термины и обозначения

Словарь основан на главах 1–2. Применяй его только к соответствующей предметной области. В конкретной задаче определение из предоставленной математической модели важнее общего словаря.

| Понятие | Предпочтительное употребление и граница |
|---|---|
| Система связи | Не заменять без причины на коммуникационную платформу или экосистему. |
| Абонент, пользователь, слой | Автор использует эти слова по контексту. В формуле не считать их автоматически взаимозаменяемыми: один абонент может иметь несколько потоков/слоев. |
| Множественный доступ | OMA, NOMA, PD-NOMA, CD-NOMA, SCMA, SDMA, RSMA сохраняют техническую область применения. |
| CD-NOMA | Неортогональный множественный доступ в кодовом домене / в домене кода. Это класс методов, включая LDS и SCMA. |
| SCMA | Множественный доступ на основе разреженных кодов. «SCMA символ», «кодовая книга», «кодовое слово», «компонент кодового слова». Не смешивать книгу, слово и суммарный символ. |
| Кодовая книга | Набор доступных кодовых слов отдельного слоя; общая кодовая книга собирает книги слоев. Уточняй, о каком уровне идет речь. |
| J, K, M | Обычно число абонентов/слоев, число ресурсных элементов/поднесущих, индекс модуляции/число слов в книге. Число ресурсных элементов равно числу поднесущих только в соответствующей модели. |
| dj, dk | Число ненулевых компонентов одного кодового слова и число слоев на одном ресурсном элементе. Для регулярной структуры J·dj = K·dk. Не переставлять индексы и показатели степени. |
| Коэффициент перегруженности | Обычно λ = J/K. Не подменять вероятностью ошибки, спектральной эффективностью или плотностью подключений. |
| Формирующая разреженная матрица F | Определяет размещение ненулевых компонентов. Не путать с материнским созвездием и готовой кодовой книгой. |
| Материнское созвездие, оператор отображения, оператор преобразования | Отдельные элементы построения книги. Символы V_j и Δ_j в исходнике употребляются не полностью последовательно; проверять определение конкретного раздела и размерности, не исправлять формулы молча. |
| MPA | Алгоритм передачи сообщений. Пользовательские и ресурсные узлы фактор-графа, вероятности и сообщения. «Детектирование» и «декодирование» сохранять по контексту; не путать с помехоустойчивым декодированием. |
| Log-MPA, Max-Log-MPA | Логарифмическое представление и приближение логарифма суммы экспонент максимумом. Сокращение стоимости операций не означает автоматического изменения порядка сложности или гарантированного равенства помехоустойчивости. |
| Помехоустойчивость | Указывать метрику: вероятность битовых/символьных ошибок, BLER и т.п. Сходные кривые в одном сценарии не означают универсального равенства. |
| Вычислительная сложность | Уточнять параметр роста и зафиксированные условия. O(KM^dk) линейна по K при фиксированных M, dk и числе итераций. Не объявлять ее линейной по всем параметрам. |
| Отношение сигнал-шум | Сохранять выбранное обозначение и нормировку; не смешивать с SINR. Дефис в термине допустим. |
| Межпользовательская интерференция | Не заменять автоматически шумом. Различать контролируемую/устранимую и остаточную составляющие по модели. |
| RSMA | В главе 1 употребляется «множественный доступ с мультиплексированием по скорости». В иных разделах может быть «на основе разделения по скорости». При продолжении главы сохранять ее установленное название. Общий и индивидуальные потоки/каналы, прекодирование, SIC используются по определениям модели. |
| Помехоустойчивое кодирование | Кодер, декодер, кодовая скорость, сигнально-кодовая конструкция (СКК), полярные и LDPC коды не подменяют операции множественного доступа. |

Сокращение раскрывается при первом необходимом вводе в самостоятельном тексте. В продолжении раздела уже введенные сокращения повторно не расшифровываются без причины. Английское название добавляй, если оно известно и полезно; не придумывай расшифровку.

Терминологическое уточнение из главы 3 (только слова и роли, не источник стиля): при продолжении этой главы сохранять установленные «общая и приватная части сообщения», «общий и приватный потоки», «прекодер общего канала», «прекодеры приватных каналов», «распределение мощности между общим и приватными каналами». Не заменять «приватный» на «индивидуальный» ради разнообразия. Мощность P и доля мощности τ различаются. В главе 1 встречается иной вариант названия RSMA; его наличие не является основанием переименовывать сущности в главе 3.

Точные утверждения о публикациях, приоритете, современных методах, эффективности и стандартах требуют предоставленного либо проверенного источника. Словарь не заменяет проверку научного содержания.
