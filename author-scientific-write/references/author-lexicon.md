# Авторский терминологический словарь

Словарь помогает выбирать авторское слово и сохранять научный смысл. Основа частот: первые две главы диссертации. Предпочтение действует внутри указанной роли, а не как глобальная замена по частоте. Глава 3 приведена только в отдельной справке в конце и не участвовала в подсчете.

## Дополнение по статьям первого автора

[Тематический словарь статей](article-lexicon.md) дополняет приведенные здесь диссертационные семейства терминами кодирования, синхронизации, сетевой архитектуры, аппаратной реализации и технологий 6G. Для этих тем прочитай соответствующую статью дополнения. При расхождении предпочтение имеет целевая глава диссертации. [Реестр источников](article-sources.md) содержит авторство, год и ограничения отбора. Частоты глав 1–2 ниже сохранены отдельно и не смешаны с частотами статей.

| Отображение и преобразование | Сохранять введенные математические роли: оператор отображения распределяет компоненты на ресурсы, оператор преобразования изменяет материнское созвездие в принятой декомпозиции. |

| Интерференция, помеха и шум | Для взаимного влияния сигналов сохранять «интерференция» с уточнением вида; «помеха» является более общим словом; «шум» использовать для заданной случайной составляющей модели. |
| Моделирование и эксперимент | Для вычислительного воспроизведения системы предпочтительны «моделирование» и «имитационное моделирование». «Натурный эксперимент» сохранять для исследования реального объекта или макета. |

| Размерность, размер, число и количество | Для параметров матриц и кодовых книг сохранять «размерность» с обозначением меняющегося параметра. «Число» и «количество» допустимы для счетных объектов; выбирать по локальной конструкции. |
| Мощность и энергия | Различать мощность сигнала, энергию бита и коэффициент распределения мощности. Сохранять «нормировка» и нормируемую величину; указывать среднее значение, когда оно входит в определение. |
| Модель канала и замирания | Сохранять конкретные «канал с АБГШ», «канал Релея», «многолучевой канал», «частотно-селективные замирания». Слово «канал» само по себе не заменяет название модели. |
| Критерий, метрика и целевая функция | «Критерий оптимизации» задает правило выбора; «целевая функция» является математическим выражением; «метрика» или «показатель эффективности» характеризует оцениваемое свойство. Сохранять выбранное автором обозначение. |
| Метод, алгоритм и подход | «Алгоритм» использовать для заданной последовательности операций; «метод» для содержательного способа решения; «подход» для более общей идеи. При ссылке на предложенный результат сохранять его устойчивое название. |
| Оценка, расчет и измерение | «Оценка» допустима для статистического или аналитического определения характеристики; «расчет» для вычисления по заданному правилу; «измерение» для получения величины средствами измерения. «Анализ» описывает исследование свойств. |
| Область и домен | «Частотная область» и «частотный домен» встречаются как способы описания представления сигнала; выбирать термин целевого раздела. «Домен мощности» и «домен кода» сохранять в названиях классов NOMA. |
| Граф, цикл, кратность и обхват | Сохранять «фактор-граф» и «граф Таннера» в принятой модели. «Обхват графа» относится к минимальной длине цикла; «кратность» использовать с тем определением, которое введено в разделе. |
| Общий и приватный: сообщение, поток, канал | Для RSMA сохранять «общий» и «приватный» в той роли, которая введена моделью. При части сообщения писать «часть», при потоке «поток», при принятом обозначении канала «канал». |
| Распределение ресурсов и планирование | Сохранять «распределение ресурсов», «распределение мощности» и «планирование» по задаче. Если введена стратегия равной скорости, описывать именно равенство скоростей абонентов. |
| Опорный и пилотный символ | Для известных приемнику символов сохранять «опорный» или «пилотный» согласно локальной терминологии. При первом вводе можно показать соответствие терминов, если оно верно в данной системе. |
| Выигрыш, повышение и улучшение | Предпочитать предметные конструкции «выигрыш составляет», «повышение помехоустойчивости», «снижение вероятности ошибок» с указанием базы и условий сравнения. При отсутствии числа описывать только установленное направление изменения. |

## Методика и границы подсчета

Проанализировано 27 файлов. Файлы с названиями, начинающимися на 1 и 2, взяты из `style-work/corpus`. Включены и разделы, отложенные для проверки стиля: эти частоты характеризуют полный авторский словарь двух глав, а не независимый обучающий набор. Частоты словаря нельзя использовать как доказательство прохождения контрольного теста.

Очистка выполнена функцией `analyze_style.paragraphs`: удалены блочные формулы, HTML-таблицы, подписи рисунков и таблиц, ссылки и служебная разметка; внутритекстовая формула заменена маркером. Аббревиатуры внутри удаленной формулы не считаются. Сохраняется проза с нумерованными пунктами. Методика измеряет очищенный текст и не претендует на счет всех надписей в диссертации.

Частота означает число вхождений перечисленных в скрипте падежных форм без учета регистра. Для существительного «абонент» учитываются формы абонент, абонента, абоненту, абонентом, абоненте, абоненты, абонентов, абонентам, абонентами, абонентах. Прилагательные «абонентский» и «многоабонентский» в этот счет не входят. Прилагательные отдельно учитываются только в явно заданных словосочетаниях. Варианты е/ё объединены лишь там, где это явно указано.

Фразы считаются при непосредственном соседстве слов. Например, счет «формирующая матрица» не включает «формирующая разреженная матрица», для которой есть отдельная строка. Вставка обозначения между словами может прервать совпадение. Слово «устройство» включает случаи в выражении «абонентское устройство»; такие частоты пересекаются и не складываются в число уникальных объектов.

Ноль означает «не встретилось при этой очистке и этих формах». Он не доказывает, что термин запрещен автором во всех предметных областях. Редкий, но точный термин следует сохранять. Терминологические ошибки, опечатки и неустойчивые обозначения исходника не являются стилистической нормой.

В каждом семействе приведен короткий буквальный фрагмент исходной строки. Это фрагмент, а не всегда полное предложение; многоточие не добавляется внутрь цитаты. Источник указан как имя файла и строка в `style-work/corpus`; исходные файлы с такими же именами находятся в Obsidian-каталогах соответствующих глав. Для самостоятельного применения скилла достаточно определения, частот и сохраненного фрагмента, повторное чтение корпуса не требуется.

Воспроизведение из корня проекта: `python style-work/lexicon_counts.py`. Скрипт читает только корпус первых двух глав и создает `style-work/lexicon-counts.json` и этот справочник. JSON сохраняет регулярные выражения, частоты, цитаты, хеши входных файлов и хеш функции очистки.

## 1. Абонент и пользователь

Для адресата или участника радиосвязи предпочтителен «абонент». «Пользователь» также авторский вариант; сохранять его в устойчивой постановке и при обсуждении сервиса. «Юзер» и «подписчик» не вводить в радиотехническое описание без отдельной предметной причины.

**Опасная подмена.** Не считать пользователя человеком, устройством и слоем одновременно: роль определяется моделью. Нулевая частота разговорного варианта характеризует этот корпус, а не все возможные темы автора.

## 4. Кодер, декодер и детектор

**Опасная подмена.** Не унифицировать эти названия. SCMA кодер и кодер помехоустойчивого кода выполняют разные отображения.

## 6. Помехоустойчивость, устойчивость, надежность

При оценке ошибок приема предпочтительна «помехоустойчивость». «Устойчивость» требует указания возмущения или свойства. «Надежность» относится к своей метрике либо требованиям сервиса. «Робастность» использовать только при содержательной робастной постановке.

**Опасная подмена.** Робастность к неопределенности канала, надежность услуги и вероятность ошибки не являются автоматически одним показателем.

## 24. Модель канала и замирания

## 25. Критерий, метрика и целевая функция

«Критерий оптимизации» задает правило выбора; «целевая функция» является математическим выражением; «метрика» или «показатель эффективности» характеризует оцениваемое свойство. Сохранять выбранное автором обозначение.

**Опасная подмена.** MED может быть косвенным критерием, BER основным показателем. Не объявлять максимум одной метрики доказанным максимумом другой.

Пример: «В рамках текущего исследования MED выступает в качестве косвенного критерия эффективности проектируемых кодовых книг.»

## 26. Метод, алгоритм и подход

«Алгоритм» использовать для заданной последовательности операций; «метод» для содержательного способа решения; «подход» для более общей идеи. При ссылке на предложенный результат сохранять его устойчивое название.

**Опасная подмена.** Не переименовывать алгоритм методом и обратно только для устранения повторов. Общая идея без шагов не становится алгоритмом.

## 27. Оценка, расчет и измерение

«Оценка» допустима для статистического или аналитического определения характеристики; «расчет» для вычисления по заданному правилу; «измерение» для получения величины средствами измерения. «Анализ» описывает исследование свойств.

**Опасная подмена.** Не называть точным расчетом статистическую оценку BER и не подменять моделирование измерением. Для оценок сохранять объем выборки и условия.

**Опасная подмена.** Не заменять любую «область» доменом: область значений, область высоких ОСШ и частотное представление имеют разные значения.

## 30. Общий и приватный: сообщение, поток, канал

Для RSMA сохранять «общий» и «приватный» в той роли, которая введена моделью. При части сообщения писать «часть», при потоке «поток», при принятом обозначении канала «канал».

**Опасная подмена.** «Приватный» не заменять на «личный», «персональный» или «частный» ради разнообразия. Общий поток и общие части отдельных сообщений различаются до и после объединения.
